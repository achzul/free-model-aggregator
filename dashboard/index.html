Free Model Aggregator — $0 edition

Every chat model on OpenRouter that costs exactly $0 per token, gathered into one searchable, comparable page. No sign-up, no key, no tracking: the catalog snapshot is bundled with this page, so it renders instantly and fully offline. The aggregator server in this repository routes live requests across ten providers' free tiers; this dashboard is its human-facing catalog.

Which free model for…

Data: OpenRouter's public model catalog (openrouter.ai/api/v1/models), filtered to models whose prompt and completion prices are both exactly "0". Free tiers are rate-limited by the provider — on OpenRouter, an account that has purchased at least 10 credits gets 1,000 free requests a day rather than 50. Prices and availability change; the snapshot stamp above says when this copy was taken. Shortlists under “Which free model for…” are simple heuristics over context size, image input and model naming — a starting point, not a benchmark.
